# Teacher-editable experiment assessments

In the teacher web portal, open **AR Labs → Edit Content** for an experiment.
The same editor is available to administrators. Existing handled-grade access
rules continue to determine which experiments a teacher sees.

**PPE Safety Check** lets the teacher add, edit or remove choices, edit their
feedback explanations, and mark all correct selections. Unchecked choices are
distractors. If no choices are marked correct, that experiment skips the PPE
check. Custom choices use a generic safety icon in the app; existing choices
keep their familiar icons.

**End-of-Experiment Mini Quiz** lets the teacher edit prompts, the four answer
choices, and the correct answer; add questions up to ten; and remove questions
while retaining at least five. Saving rejects blank prompts or choices,
duplicate answer choices, missing correct answers, and question counts outside
5–10. PPE choice names and identifiers must be unique, with feedback supplied.

Click **Save Changes**, then confirm the save. Students receive these settings
when they next open the experiment. The app reads one snapshot before the PPE
check and keeps it through the quiz, grading and reset, so a teacher's later
edits cannot alter the current run's answer key. PPE first-attempt scoring and
the four-category rubric remain in effect; quiz scores use the actual configured
question count.

## Stored fields

Settings are saved on the existing `ar_experiments/{experimentId}` document:

```json
{
  "ppeAssessment": {
    "options": [
      {"id": "goggles", "label": "Safety goggles", "reason": "Feedback explanation"}
    ],
    "requiredIds": ["goggles"]
  },
  "assessmentQuestions": [
    {
      "prompt": "Question text",
      "options": ["Choice A", "Choice B", "Choice C", "Choice D"],
      "correctOption": 1
    }
  ]
}
```

The abbreviated example shows one question; saved quizzes require 5–10.
`correctOption` is a zero-based index, so `1` identifies Choice B. Choice IDs are
generated by the editor and retained when names change. Removing a PPE choice
also removes its ID from the correct-selection list.

Documents without these fields retain the built-in assessments. The app also
rejects malformed saved PPE or quizzes and falls back independently for each
section. The editor starts with the same built-in choices and five questions
for existing experiments, so teachers can edit them without a data migration.

The existing approved-teacher update permission for `ar_experiments` covers
these fields; see `admin_web/TEACHER_PORTAL_FIRESTORE_RULES.md` if teacher saves
are denied. This change does not publish Firestore rules, update records, or
deploy hosting automatically. Publish the rebuilt web portal and rebuild the
Flutter app to release it.

For developers: `python scripts/export_assessment_defaults.py` regenerates the
web defaults from Flutter's built-in PPE and question data. The assessment test
checks their parity for every experiment.
